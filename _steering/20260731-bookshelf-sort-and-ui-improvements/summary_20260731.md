## 🎯 完了したタスク

### 1. 🛒 買い出しリストからの削除・ステータス同期修正
- [x] **買い出しリスト削除時のステータスリセット**: 買い出しリストから本を削除した際、該当巻のステータスが `WANTED` (買いたい本 / 🟨) であれば自動的に `UNREGISTERED` (未所持 / ⬜) へ連動リセットされるよう `BookRepository` および `BookDao` を更新。 ✅ 2026-07-31
- [x] **ワンタップ「買った！」機能の追加**: 買い出しリスト各アイテムに「買った！」(🟩 緑色ボタン) を追加。タップで即座に `OWNED` (所持済み) へ移行し、買い出しリストから自動削除。 ✅ 2026-07-31

### 2. 📚 本棚並べ替え（ソート・フィルタ・永続化）機能の実装
- [x] **5つのソート基準**: 登録日時順、最終更新順、買いたい本優先、所持冊数順、コンプリート度順をサポート。（※不正確だったタイトル順は撤廃） ✅ 2026-07-31
- [x] **直感的なソートヘッダーUI**: `FilterChip` ＋ `DropdownMenu` ＋ 昇順/降順切替アイコンボタン（`⬆` / `⬇`）を配置。 ✅ 2026-07-31
- [x] **ソート設定の永続保存**: `UserPreferencesRepository` (`SharedPreferences`) を新設し、アプリ再起動後も選択されたソート条件および昇降順フラグを保持・復元。 ✅ 2026-07-31
- [x] **スクロール位置の自動リセット**: ソート変更・昇降順切替時にページ最上部 (`scrollToItem(0)`) へ移動するスクロール制御を追加。
- [x] **ポップアップ状態の追従保護**: `LazyVerticalGrid` の `gridItems` に `key = { it.series.id }` を付与し、ソート順入れ替え時にモーダルやカードの状態が別作品にずれないよう修正。

### 3. 📐 買い出しページのレイアウト ＆ 視認性強化
- [x] **タイトル全文字表示 ＆ 長文溢れ対策**: 作品タイトルを省略（`...`）せず全文字折り返し表示。長文タイトルでも右側の操作ボタンが画面外に押し出されないよう `weight(1f)` を設定。
- [x] **独立した巻数強調バッジ**: 上部ラベル横に **`[ 15巻 ]`** の視認性の高い黄色強調チップバッジを新設。

### 4. 🔍 検索照合ページのインクリメンタル検索修正
- [x] **DB全件フィルタリング**: 検索窓入力時に前回絞り込み後のリストからではなく、常にDB全件のシリーズリストから一瞬で正確にインクリメンタル検索されるよう `searchQueryFlow` と `isMangaOnlyFlow` を Coroutines `combine` に集約。

### 5. 🖼️ 表紙画像の取得・保持・フォールバック表示の改善
- [x] **公開HTTPS書影URLへの補填**: 相対パスを OpenBD の完全な HTTPS URL (`https://cover.openbd.jp/...`) へ更新。
- [x] **多重フォールバックロジック**: `シリーズ表紙` ➔ `1巻表紙` ➔ `他巻表紙` ➔ `電子書籍風カバー` の自動探索フォールバックを組み込み。
- [x] **「作品追加」ダイアログからの画像保存バグ修正**: Web API検索から「作品追加」ダイアログ経由で登録する際、`item.coverUrl` を受け取って `SeriesEntity` へ確実にセットして保存するよう修正。ダイアログ内での画像サムネイル表示を追加。
