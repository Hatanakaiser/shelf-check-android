# ユビキタス言語定義書 (Android Native / Ubiquitous Language)

- **文書バージョン**: v1.1.0 (Kindle風本棚機能追加版)
- **更新日**: 2026-07-28
- **対象ドメイン**: ShelfCheck for Android

---

## 1. 主要用語 ＆ コード表現定義

| 日本語用語 | 英語コード表記 (Kotlin) | 判定カラー | 説明・定義 |
| :--- | :--- | :--- | :--- |
| **所持済み** | `BookStatus.OWNED` | 🟥 赤 (Red) | 手元に所有している本。二重購入警告対象。 |
| **買い出し対象** | `BookStatus.WANTED` | 🟩 緑 (Green) | 探している本・買い出しリスト項目。購入推奨。 |
| **売却済み** | `BookStatus.SOLD` | 🟧 オレンジ (Orange) | 過去に読んで手放した本。再購入注意。 |
| **未所持** | `BookStatus.UNREGISTERED` | ⬜ グレー | データベース上でまだ所持していない巻。 |
| **Kindle風本棚** | `BookshelfSeriesGroup` | - | Kindleライブラリのように蔵書が作品シリーズ単位でアルバム風にまとまって並ぶ本棚表示。 |
| **買い物モード** | `isShoppingMode` | - | 店頭での照合特化モード。買ったらワンタップで所持へ更新。 |
| **巻数マトリクス** | `VolumeMatrix` | - | `[1][2][3][4(未)]` のブロック状に巻数状態を一覧表示・トグル変更できるUI。 |
| **ハプティクス** | `HapticFeedback` | - | 音を出せない静かな店舗内で振動（バイブ）により判定を知らせる機能。 |
