# 初期開発スコープ定義書 (MVP / Phase 1 Scope)

- **文書バージョン**: v1.0.0
- **作成日**: 2026-07-28
- **対象システム**: ShelfCheck for Android

---

## 🎯 初期バージョン (MVP / Phase 1) の目的

アプリ全体の完成を待たずに、**「店頭でのテキスト爆速照合」**と**「Kindleライブラリ風本棚」**の体験を最速で手元でテスト・確認できるプロダクトを構築する。

---

## 📦 初期実装に含める機能 (MVP Scope)

| 機能エリア        | 実装する内容 (Phase 1)                                                        | 実装を見送る内容 (Phase 2へ延期) |
| :----------- | :---------------------------------------------------------------------- | :-------------------- |
| **1. 照合・検索** | **爆速テキストインクリメンタル検索** (`"ゆゆ"`, `"呪術"`)<br>＋ **4色全画面照合アラート** (🟥/🟩/🟧/⬜) | ML Kit カメラバーコード照合     |
| **2. 本棚**    | **Kindleライブラリ風 シリーズ集約本棚**<br>＋ **巻数ブロックマトリクス (`[1][2][3]`)**            | 複雑なカテゴリタグ編集           |
| **3. 買い物**   | **買い出しリスト一覧** ＋ **「買った！」ワンタップ所持移行**                                     | ECサイト（Amazon/楽天）購入リンク |
| **4. データ**   | **完全ローカル保存 (Room DB / IndexedDB)**<br>＋ **初期サンプルシードデータ (ゆゆ式, 呪術廻戦等)**   | オンライン同期・クラウドバックアップ    |

---

## 📱 初期バージョンで体験できるシチュエーション

1. **店舗での0.1秒照合**:
   - 検索窓に「ゆゆ」と打つ ➔ 一瞬で『ゆゆ式』の1巻〜15巻の所持状況が表示。
   - 1巻をタップ ➔ 🟥 **「⚠️ すでに所持しています！」**
   - 15巻をタップ ➔ 🟩 **「✅ 探していた本です！（買い出し対象）」**
2. **Kindle風本棚**:
   - 「本棚」タブを開くと、『ゆゆ式 (1/15巻所持)』『呪術廻戦 (5/26巻所持)』がきれいなカバーカードで一目瞭然。
3. **買い物完了**:
   - 「買い出し」タブを開き、店頭で買った本（例: ゆゆ式15巻）の「買った！」をタップ ➔ 即座に本棚の所持データへ更新。
