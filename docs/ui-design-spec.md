## 1. 画面別 UI 設計仕様

### 1.1 S-3: Kindleライブラリ風 シリーズ本棚画面 (Bookshelf Screen)

#### グリッドレイアウト (Kindle-style Grid)
- 2列〜3列のレスポンシブグリッドカード。
- **カード構成**:
  - アスペクト比 **3:4** の大型シリーズカバー画像。
  - 画像右上: **所持数バッジ** (`"5 / 26"` または `"全巻所持 🎉"`)
  - カード下部: タイトル（太字） ＋ 著者名 ＋ 所持プログレスバー (`5/26`%)
- **フィルタリングチップ (Filter Chips)**:
  - 画面上部に Material 3 の `FilterChip` を配置 (`[すべて]` `[連載中]` `[完結済み]` `[買い出し対象あり]`)

#### シリーズタップ時の詳細展開 (Series Detail BottomSheet / Screen)
- シリーズカードをタップすると Modal BottomSheet または詳細画面が起動。
- ヘッダー: シリーズカバー ＋ 作品概要 ＋ 著者 ＋ 全巻数
- コンテンツ: **1巻〜全巻のグリッド配置**
  - 所持巻: 🟥 赤枠 ＋ 「所持」
  - 買い出し対象巻: 🟩 緑枠 ＋ 「買い出し対象」
  - 売却済み巻: 🟧 オレンジ枠 ＋ 「売却済」
  - 未所持巻: ⬜ グレー枠
- 各巻タップで状態切り替えダイアログ / トグル処理。
